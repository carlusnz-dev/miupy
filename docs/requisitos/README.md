# Requisitos

- [`requisitos.md`](requisitos.md): lista única de requisitos (`RF-NN` funcionais, `RNF-NN` não
  funcionais), prioridade e como anotar o código.

Para adicionar um requisito, inclua uma linha na tabela com o próximo ID livre. IDs não são
reaproveitados nem renumerados, porque o código aponta para eles.
